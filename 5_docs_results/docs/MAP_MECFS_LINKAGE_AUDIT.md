## Bottom line
* **Wearable/actigraphy, HRV, orthostatic and CPET data cannot truthfully be linked to omics with openly downloadable data.** In every open file these measurements carry group labels only (HV / PI-ME/CFS) or figure-local letters, never a participant identifier (2 wearable-type modalities obtained, all without IDs; 0 wearable x omics pairs have comparable identifiers). The per-participant files (free-living accelerometry, HRV, tilt, CPET) exist only on mapMECFS, which requires an account.
* **Omics x omics linkage is real but limited to the NIH study number.** 5 open omics modalities carry NIH study numbers (1xx = healthy volunteer, 3xx = PI-ME/CFS), directly or via the SomaLogic crosswalk published in GSE251790. Union: 47 study numbers (24 with 1xx, 23 with 3xx). The paper's analytic cohort is 21 HV + 17 PI-ME/CFS, so the deposits include participants outside it, and no open file flags which.
* **mapMECFS**: the CKAN `package_search` catalogue metadata is public, but 29 of 29 anonymous file-download probes returned HTTP 403 with the page text "Login Required. Please login to view this feature." (2 CKAN API actions also returned 403 'Authentication is required'; the group landing page answers HTTP 200 but shows the same login notice.) The paper states: "Accessing Map ME/CFS data requires signing up for an account but otherwise access to the data is unrestricted (Creative Commons BY 4.0)." No account was created, so 85 mapMECFS data files are catalogued as not automatable.
* Consequence for the engine: the molecular results from this study enter as **condition-level molecular enrichment** (`condition_molecular_evidence__mapmecfs`). The participant-linked omics table links omics to omics only; it is not "patient multi-omics" with wearable physiology.

## 6. Can wearable/actigraphy and omics be linked?
**No, not with openly downloadable data.** Evidence:

* `hrv_24h_time_domain` (Nature Source Data, Figure 2A frequency domain.xlsx): 33 per-participant rows labelled only by group {'HV': 19, 'PI-ME/CFS': 14}; no participant identifier.
* `hrv_24h_heart_rate_5min` (Nature Source Data, Figure 2G.xlsx): 33 per-participant columns labelled only by group {'HV': 20, 'PI-ME/CFS': 13}; no participant identifier.
* `baroreflex_gain` (Nature Source Data, Figure 2H.xlsx): 35 per-participant rows labelled only by group {'HV': 19, 'PI-ME/CFS': 16}; no participant identifier.
* `orthostatic_tilt_catecholamines` (Nature Source Data, Figure S4A.csv): 32 per-participant rows labelled only by group {'PI-ME/CFS': 16, 'HV': 16}; no participant identifier.
* `cpet_peak_vo2` (Nature Source Data, Figure 5D.xlsx): 17 per-participant rows labelled only by group {'HV': 9, 'PI-ME/CFS': 8}; no participant identifier.
* `cpet_heart_rate_curve` (Nature Source Data, Figure 5G.xlsx): 17 per-participant columns labelled only by group {'HV': 9, 'PI-ME/CFS': 8}; no participant identifier.
* 10 per-participant wearable/autonomic/exercise files are listed on mapMECFS and are gated: Heart Rate Variability Dataset (CSV, 3165 bytes); HF Power Heart Rate Variability Dataset (CSV, 102818 bytes); LF Power Heart Rate Variability Dataset (CSV, 102497 bytes); Tilt Catecholamines Dataset (CSV, 23315 bytes); Head-up Tilt Table Testing (CSV, 2056 bytes); Valsalva Maneuver Assessment (CSV, 2766 bytes); SD1 Heart Rate Variability Dataset (CSV, 9667 bytes); SD2 Heart Rate Variability Dataset (CSV, 9635 bytes); Free Living Accelerometry (CSV, 2778 bytes); Cardiopulmonary Exercise Tests (CPET) (CSV, 4748 bytes).
* Their identifier scheme is unknown without access. The only mapMECFS-format IDs we could see (GitHub EEfRT file, 'map000NNN-GG-VV') have no public crosswalk to the NIH study numbers used by the GEO omics deposits. Even with a mapMECFS account, linkage to GEO would require that crosswalk; linkage within mapMECFS (e.g. accelerometry to mapMECFS-hosted RNA-seq/SomaLogic tables) might be possible but is UNKNOWN / NOT AVAILABLE until audited with access.
* Therefore `participant_wearable_features__mapmecfs` is not produced.
