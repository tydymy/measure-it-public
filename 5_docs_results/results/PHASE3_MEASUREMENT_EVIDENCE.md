**What this is.** SPEC Phase 3 for four demo phenotypes: observable signals, candidate measurement classes and bundles, and evidence per source, with five dimensions kept separate. **What it is not.** No composite score; no ranking across dimensions. A phenotype signal is a group-level association in a public dataset, never an individual finding. Registered trials and funded grants show research activity, not that a measurement works. An FDA record is a deployment-readiness signal, not evidence that a device diagnoses the illness. Molecular context is condition-level molecular enrichment, not person-linked multi-omics and not mechanism.

## Limitations

* Label strength: no public dataset here carries a clinical diagnosis of any target condition. The strongest condition label is Uwakwe's self-reported Long COVID (n = 126); ME/CFS is a constructed NHANES proxy; fibromyalgia, migraine, IBS, insomnia and myalgia are rx reason codes (2013-14 only; treated conditions, and a drug-defined label may reflect the medication).
* NHANES is cross-sectional, unweighted and wrist-accelerometry only; its effects are age/sex-adjusted group differences, not diagnostic performance. The model increment uses all 26 features, so it is not class-specific.
* The acute COVID-19 cohorts describe acute illness and recovery; they are not a Long COVID label and the step drop is expected illness behaviour.
* The verdict is a within-dimension summary with fixed thresholds (q < 0.05, |effect| >= 0.2); see the sensitivity section. Bundle and registry values are highest-member / highest-condition summaries; the components are kept.
* measurement_evidence_strength, technology_maturity and regulatory_visibility inherit the text-mining precision caveats and FDA mapping confidence of the measurement layer (results/MEASUREMENT_DISCOVERY.md).
* Phenotype -> technology links come from the phenotype-axis map (text match of curated axis signals) plus labelled curated additions; they state what could observe a phenotype, not what has been validated.
* 'Best effect' is the largest |effect| among FDR-surviving features (or among all features when none survives). It is selected, so it is biased away from zero (winner's curse), and its CI is the nominal per-feature CI, not adjusted for the selection. Use n_features_fdr_meaningful and the full signature (signature: object ids) for the size of the signal.
* A Phase 3 row's reference label need not belong to a target condition: sleep/circadian rests on NHANES rx_insomnia, orthostatic/autonomic on Uwakwe Long COVID, post-infection recovery on acute COVID-19 cohorts. A Phase 3 verdict is therefore not a result for any particular condition; the condition-level value is phenotype_signal_strength in condition_measurement_evidence. discover_candidate_measurements marks this with phenotype_evidence.applies_to_queried_condition.
* Circularity: the ME/CFS-like proxy and the functional_limitation label are defined partly by self-reported activity limitation, so their accelerometry activity differences are partly expected from the definition. No NHANES label is defined from the accelerometry itself, and no model here was tuned outside its folds, because this module fits nothing: it re-reads the producers' cross-validated results.
